# HTP MoE decode benchmark — LFM2.5-8B-A1B on the Galaxy S25 Ultra

Contract: `docs/plans/0001-htp-moe-decode-agent-system.md`. The supervisor
edits this file from filled `docs/measurements/*.md`; nobody else writes
numbers here.

## Method

`nntrainer_causallm` on the phone, `NNTR_NUM_THREADS=8`, prompt 512 tokens,
generation 64 / 512 / 1024 tokens, two runs per cell, non-profile binary.
Decode tok/s is reported over the whole generation and over the last 64
tokens. Every sitting starts with variant A (the unchanged reference
binary) and every other variant is read against it inside that sitting.
Accuracy: generated text identical to the CPU `q40` run of the same
prompt (y/n), `NNTR_L2_DIFF` when DSP arithmetic changed.

Unit: **any Galaxy S25 Ultra** (user decision 2026-09-22, contract §12).
A handoff never names a serial; the filled handoff records the serial
actually used, every row here carries it, and numbers are compared only
as an A/B inside one sitting. Where two sittings happen to share a unit,
the same-unit drift is recorded as a note (LEDGER rule 13). Rows from the
PR author's device are labelled `(PR)`. Every row of this project so far
(#77, #94, #88, #105, #100, #113) ran on `R3CY205ZMND` (SM-S938N). The NPU
**"now"** is **#100's variant A** (2026-09-23, `4bf1fdac`) = `htp_moe`
head code (`db7c6eb2` = PR #108's `8e121dbe`) with the M=1 GEMV **on by
default**; PR #112 changes only `test/`, so this A is the head's own
control. It replaces #105's A (27.74 / 26.88 / 24.83, `da41340b`), which
it reproduces within +0.4 / +0.8 / +6.5 % on the same unit and path.
**Default since PR #115 (`c45d4433`, cycle 13):** #113's D192 cell —
one-row loop + 192 KB `l2fetch` lead — is the M=1 GEMV default on
`htp_moe` (`HVX_GEMV_M1_ROWS1=1u`, `HVX_GEMV_PF_LEAD_KB=192u`, user
decision 2026-09-23, LEDGER rule 33). **Variant A of every sitting from
here on is D192**, and its log must print exactly one
`[HTP] moe m1 gemv: on (applied=0x103c1) lead=192KB rows1=1 source=default`;
an A log with `applied=0x1`, `lead=default` or `rows1=default` is the old
default and voids the sitting (rule 21). The old cell stays reachable as
**A0** = `NNTR_MOE_HTP_GEMV_LEAD_KB=0 NNTR_MOE_HTP_GEMV_ROWS1=0`
(`applied=0xc1`). D192 read **28.57 / 27.71 / 27.04** against #113's own
A 27.44 / 26.83 / 25.93 (+4.11 / +3.29 / +4.26 %, text byte-identical).
"Now" **stays at #100 A** until the flipped default is measured as the
control of its own sitting (contract §4.2: a lever cell never becomes
the reference row); that confirmation rides **#117's handoff** as A vs
A0 (no handoff of its own; `113-m1-gemv-lead-matrix.md` "Landed
defaults", `37fffcb4`). #113's A (`0x1`, four-row, lead 0) reproduces
#100 A within −1.5 / −1.0 / −2.0 %.
**PR #108 merged as `8e121dbe` (cycle 10): every variant A is the GEMV
default** (then `[HTP] moe m1 gemv: on (applied=0x1) source=default`,
superseded by the D192 banner above since PR #115; an A log without
`source=default` voids the sitting) — #100's six A logs all carry it
exactly once. #108 had no sitting of its own; its ride-along cells rode
#100's handoff and are read there (A vs A0 = **+13.5 %** at G=64, the
fixed M==1 row, the GEMV-vs-HMX transport line). The CPU "now" stays
from #94 sitting 2 (`dad0f476`); none of #88, #105, #100 or #113 ran a
CPU cell.
