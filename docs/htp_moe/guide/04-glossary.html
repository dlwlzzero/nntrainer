4. Glossary — every acronym and term on these pages

definitions as used in contract docs/plans/0001-…, LEDGER.md, BENCHMARK.md, doc 49 §3–§4 and the code under nntrainer/tensor/htp_backend/.

A/B
Two variants run in the same sitting on the same phone; only their ratio is a verdict (LEDGER rule 9).
acc, acc_read
The HMX accumulator (64 rows × 32 int32) and the instruction that copies it out to VTCM; the HMX stalls while it is read. Profile column acc.
adb
Android Debug Bridge: the USB tool that pushes files to the phone and runs commands on it. Agents never run it.
AEE_EBADPARM (0x8000040E)
FastRPC's "bad parameter" error; on this project it almost always means a stale skel (rule 3).
AH tile
"Activation, HMX order": 64 rows × 32 k-values of u8, 2048 B, the layout of the activation operand the HMX reads.
arena (ION arena)
3840 MiB of ION memory in 256 MiB chunks, mapped once into the DSP, holding all 1408 expert weight matrices in WH order.
ARM
The phone's CPU cores (Cortex big.LITTLE), where the app and everything not on the DSP runs.
bus vote
A request the DSP makes for DDR bandwidth (40 GB/s at session open); the novote skel drops it. Worth ≤ 4 % in #77.
cDSP
The compute DSP domain of the Snapdragon; the FastRPC session opens with _dom=cdsp.
control (variant A)
The unchanged reference binary that opens every sitting.
conv block / causal_conv1d
LFM2's non-attention mixer: two FCs around a short depthwise convolution with two gating multiplies.
CPU control
The q40 model on the CPU: the tok/s floor the NPU must beat.
DCVS / DVFS
Dynamic clock and voltage scaling: the DSP may lower its clock when idle; a candidate cause for run-to-run drift.
decode
Generating tokens one at a time after the prompt; M = 1 everywhere.
DDR (LPDDR5X)
The phone's main memory; 34–38 GB/s measured for one reader, the speed limit of decode.
dequant / requant / quant
int32 → f32 with scales (dequant), f32 → u8 for the next matrix (requant), the first f32 → u8 of the activation row (quant).
DMA
Direct memory access: the DSP's copy engine, driven by descriptors (2D: row bytes, stride, row count) through a ring; how weights get from DDR to VTCM.
drain
Profile column: time spent waiting for a DMA transfer that was not hidden behind compute.
DSP
Digital signal processor; here the Hexagon core inside the HTP.
dspqueue
Hexagon SDK's low-latency ARM↔DSP queue; deferred alternative to plain FastRPC calls.
expert
One of 32 small FFNs in a MoE layer: gate_up [2048 × 3584] and down [1792 × 2048], 5.25 MiB in int4.
FastRPC
Qualcomm's remote procedure call from ARM to DSP; one call = marshal arguments, wake a DSP thread, run the skel function, return.
FC (fully_connected)
A dense matrix multiply layer (in_proj, out_proj, q/k/v/o, dense FFN).
FFN
Feed-forward network: the gate/up → SwiGLU → down block of a layer; MoE or dense.
GEMM / GEMV
General matrix–matrix / matrix–vector multiply. Decode is GEMV (M = 1).
gather / scatter
Gather: bring a block's activation rows (and scale/zp) to where the HMX reads; scatter: out[row] += weight · result, the weighted sum of the experts.
gen (G)
Generation length in tokens: 64 / 512 / 1024 in every handoff.
greedy decoding
do_sample: false; the argmax token every step, so runs are repeatable.
handoff
A measurement document (docs/measurements/<issue>-<slug>.md) the user runs on the phone in one sitting and fills in.
HexKL
Qualcomm's kernel library exposing the HMX (libhexkl_micro.a on the DSP, libsdkl.so on the ARM).
HMX
Hexagon Matrix eXtension: the matrix unit; one instruction multiplies a 64 × 32 u8 tile by a 32 × 32 i4 tile into the accumulator.
host / dsp / transport
Profile columns: host = the call as timed by the ARM; dsp = as timed by the DSP; transport = host − dsp, the round trip.
HTP
Hexagon Tensor Processor: Qualcomm's name for the NPU (DSP + HVX + HMX + VTCM).
HVX
Hexagon Vector eXtensions: the DSP's 1024-bit SIMD unit; four contexts (one per thread that owns one).
IDL / qaic / stub / skel
The interface file nntr_hvx.idl; the generator; the ARM-side caller code; the DSP-side receiver library libnntr_hvx_skel.so.
int4 (i4) / u8 / int32 / f32
4-bit signed weights; 8-bit unsigned activations; 32-bit integer sums; 32-bit floats.
ION
Android's shared-memory allocator (rpcmem): buffers both ARM and DSP can map; uncached on the DSP side.
KV cache
Stored keys and values of past positions that attention reads at decode.
l2fetch
DSP instruction that prefetches a 2D region into L2 ahead of vector loads.
LEDGER / BENCHMARK
docs/htp_moe/LEDGER.md: rules learned on silicon, verdicts, open items; BENCHMARK.md: goals and every measured row.
LFM2.5-8B-A1B
The model: 8 B parameters total, ≈ 1 B active per token (top-4 of 32 experts).
lm_head
The final projection to vocabulary logits; tied to the embedding (same matrix, 128000 × 2048).
M, K, N
Matrix shapes: M rows of activation, K reduction length, N output columns. Expert gate_up: M × 2048 × 3584.
M0-PROF
NNTR_M0_PROFILE=1's ARM-side per-MoE-layer stage line.
marshalling
Packing call arguments for FastRPC; #77 B's verdict for what the transport cost is.
md5
Checksum used to identify every pushed binary and model file.
mm
Profile column: HMX instruction issue time, timed by difference.
MoE
Mixture of experts: a router picks a few experts per token; here top-4 of 32 in 22 layers.
NDK
Android Native Development Kit: the ARM cross-compiler (r30 here).
NPU
Neural processing unit; in this project the HTP.
one call per token
The target shape: the whole layer stack resident on the DSP so a token costs one FastRPC round trip (LEDGER ⑨).
PD (unsigned PD)
Process domain on the DSP; "unsigned" lets a non-signed skel run.
poll QoS (qos_mode=2)
The latency setting that keeps a DSP thread polling instead of sleeping between calls.
PR (#4327)
The upstream pull request this branch is frozen from; its docs are docs/htp_attention/*.
prefill
Processing the prompt (512 tokens) in one pass; M ≫ 1; the −5 % gate on every change.
profile build (--profile)
An app build that prints per-node totals; never read for tok/s (rule 1).
Q4_0
4-bit block quantization (32 weights per scale) the CPU kernels read.
QS4CX / QS4CX_WH
4-bit per-channel quantization; the WH variant is pre-arranged in HMX tile order and has no CPU path.
RMSNorm
Root-mean-square normalization, before each mixer and each FFN.
RoPE
Rotary position embedding applied to q and k in attention.
router / top-k
The small FP32 matrix and the sigmoid + bias ranking that choose 4 experts and their weights.
RPC
Remote procedure call; see FastRPC.
RSS (peak memory)
Resident set size the app reports at the end of a run, in KB.
rung / gate
The verification ladder: 0 format, 1 host build + checks, 2 skel, 3 Android app + device gtest, 4 device handoff.
SDK (Hexagon SDK 6.4.0.1)
Qualcomm's DSP toolchain.
SiLU / SwiGLU
silu(x) = x · sigmoid(x); SwiGLU = silu(gate) · up, the FFN's non-linearity.
sitting
One uninterrupted session on the phone; the unit within which numbers are comparable.
SMMU
The IOMMU that maps ION buffers into the DSP's address space.
stage
Profile column: DMA copies of the activation in and the output out of the ION buffers.
tok/s, TPS
Tokens per second; the app prints "TPS".
unit
A specific phone: R3CY10WM83Y (reference), R3CY205ZMND (second unit, #77), R5KL30G6MLT (PR author).
v79
The Hexagon architecture version in the Snapdragon 8 Elite.
vrmpy
HVX multiply-accumulate of four u8 × i8 products per lane; the GEMV's inner instruction.
VTCM
Vector tightly-coupled memory: 8 MiB of on-chip SRAM the HMX reads from; filled only by DMA.
wall
One of the three measured limits of the decode MoE call: HMX 64-row tile, weight DMA rate, FastRPC transport.
WH tile
"Weight, HMX order": 32 k × 32 n int4, 512 B, the layout the HMX (and the HVX GEMV) reads.
worker pool
Three DSP threads with HVX contexts that run epilogues, requant and scatter behind the HMX.
zp (zero point)
The offset of an asymmetric u8 quantization, per row, alongside its scale.
