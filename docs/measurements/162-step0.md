## Why

1. Lever (a), CPU decode attention: `MhaM1Phases.Decode` splits the decode
   `mha_core` into kcache / softmax / vcache per L and projects what
   `split4` (a1) and `kv_ilp` (a2) would save, bit-identically (`bad=0`).
   OP-TIME's attention row at G=1024 gives the coverage ratio C.
2. Lever (b), prefetch overlap: `PrefetchOverlap` now runs under the app's
   bypass word `0x703e1`. Cold and warm cells decide P′. The `l2` cells
   (`NNTR_MOE_DMA_BYPASS=0`) tie this sitting to #90's.

The decision rules (coverage C, a1/a2 ≥ 0.15 ms, P′, the 1.3 ms sum) are
plan §4 step 0b. The supervisor applies them to the tables below.

## Steps (orchestrator; **device measurement unavoidable**)

The whole sitting is one script. It does steps 0–7 of plan §4 step 0b, with
every expected count checked, and it stops on a stale skel or `err=0x8000040e`:

```
bash /local/mnt/workspace/htp_moe/162/run_step0.sh R3CY10WM83Y
```

Logs go to `/local/mnt/workspace/htp_moe/162/logs0/` and the summary to
`logs0/sitting.out`. The last line reads `expectation mismatches: 0` when
every expected line was seen. The script's helpers and commands are the plan's:

```
W=/local/mnt/workspace/htp_moe/162; L=$W/logs0; S=R3CY10WM83Y
D=/data/local/tmp/nntrainer/causallm/s162; M=/data/local/tmp/nntrainer/causallm/models/q40-qs4cx-wh
therm() { adb -s $S shell dumpsys battery | grep -E 'level|temperature'; adb -s $S shell cat /sys/class/thermal/thermal_zone0/temp; }
probe() { # probe <log> <gtest filter> [env]
  adb -s $S shell "cd $D && md5sum libnntr_hvx_skel.so unittest_hvx_dma_probe && \
    $3 LD_LIBRARY_PATH=. ADSP_LIBRARY_PATH=. ./unittest_hvx_dma_probe --gtest_filter='$2'" 2>&1 \
    | tee $L/$1.log | grep -E 'md5|^PREFETCH_(CONFIG|COLD|OVERLAP)|^DMA_SETTINGS_MEAN|INVALID|PASSED|FAILED'; }
run() { # run <G> <log>
  adb -s $S shell "cd $D && \
    sed -i 's/\"num_to_generate\": [0-9]*/\"num_to_generate\": $1/' $M/nntr_config.json && \
    grep num_to_generate $M/nntr_config.json && md5sum libnntr_hvx_skel.so nntrainer_causallm libnntrainer.so && \
    NNTR_NUM_THREADS=8 NNTR_OP_TIME=1 LD_LIBRARY_PATH=. ADSP_LIBRARY_PATH=. \
    ./nntrainer_causallm $M \"\$(cat $D/prompt512.txt)\"" \
    2>&1 | tee $L/$2.log | grep -E '^(prefill|generation|peak memory)|dspq:|moe m1 gemv|\[OP-TIME\] (step|moe)'; }
```

0. `adb devices` (every serial recorded in `devices.log`), checkpoint 0,
   screen off (`input keyevent 223`), then wait up to 20 min for zone0
   ≤ 35 °C. The charger must be plugged in by hand.
1. Install: push `set/.` to `$D`, drop the pushed `md5.txt`, `chmod 755`
   the three executables, device `md5sum` diffed against `set/md5.txt`
   (`MD5 OK`, else stop). Then the #158 config block (greedy,
   `bad_word_ids [124900]`, `moe_engine: htp`). Expected echo:
   `do_sample": false`, `init_seq_len": 512`, `moe_engine": "htp"`,
   `moe_htp_layers": ""`.
2. `probe cold_bp '*DmaSettings*:*PrefetchOverlap*'`. Expected: 6
   `DMA_SETTINGS_MEAN`, 12 `PREFETCH_OVERLAP`, 0 `INVALID`, `PREFETCH_CONFIG
   readers=8 workers=7 ring_mib=200 sets=16 opts=0x703e1 bypass=1
   chunk_bytes=268435456`, `DMA_SETTINGS_MEAN src_bypass=0 queues=1 gbs≈37`
   and `src_bypass=1 queues=1 gbs≈69`, `[  PASSED  ] 2 tests`.
   Stop on the echo failure `the skel does not know #117's feed bit` (stale
   skel) or `err=0x8000040e`.
3. `probe l2 '*PrefetchOverlap*' NNTR_MOE_DMA_BYPASS=0`: `PREFETCH_CONFIG …
   opts=0x303e1 bypass=0 …`. Then checkpoint 1.
4. `NNTR_NUM_THREADS=8 ./unittest_nntrainer_cpu_backend_fp16
   --gtest_filter='AttnM1F16Det.*:MhaM1Phases.*'`: 12 `MHA_M1_PHASE` lines
   (3 L × 4 impl), each with `threads=8`, none with `bad=[1-9]`; every
   `ATTN_M1_F16 … bad=0`.
5. `run 1024 A_G1024_r1; run 1024 A_G1024_r2`. Each log has, once:
   `[HTP] moe m1 gemv: on (applied=0x703e1) lead=192KB rows1=1 feed=vtcm
   dma_bypass=1 source=default`, `dspq: on`, `dspq: close calls=22528
   served=22528 bad=0`. A log with `dma_bypass=0` or without `dspq: on` is
   void (rules 36, 43). Then checkpoint 2.
6. `probe warm_bp '*PrefetchOverlap*'`, then checkpoint 3.
7. Reports: `python3 tools/htp/op_time_report.py $L/A_G1024_r{1,2}.log`, and
   the `PREFETCH_COLD` / `PREFETCH_OVERLAP` lines at S = 4 and 10 of
   `cold_bp`, `l2` and `warm_bp`.
