## 실행 메모 (재현 시 주의)

- **`ADSP_LIBRARY_PATH` 구분자는 세미콜론(`;`)** — 콜론(`:`)으로 주면 DSP가 skel을 못 찾아
  `htp_ops_open`이 `0x80000406`(**AEE_EUNABLETOLOAD**, AEE_EOFFSET 0x80000400 + 0x6)로 실패.
  올바른 예: `ADSP_LIBRARY_PATH='/data/local/tmp/.../lib;/vendor/lib/rfsa/adsp;/vendor/dsp/cdsp'`.
- 단말 배치: 호스트 libs(`libnntrainer.so`, `libcausallm_core.so`, `libccapi-nntrainer.so`,
  `libc++_shared.so`, `libhtp_ops.so`) + DSP skel(`libhtp_ops_skel.so`)을 `LIBDIR`에 두고
  `LD_LIBRARY_PATH=LIBDIR`, `ADSP_LIBRARY_PATH`에 LIBDIR 포함.
- 모델 디렉터리(`config.json`/`generation_config.json`/`tokenizer*.json`/`nntr_config.json`/weight bin)는
  nntr_config의 `tokenizer_file` 절대경로와 일치하는 곳에 둔다.
