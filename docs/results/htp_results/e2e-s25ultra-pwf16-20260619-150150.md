# HTP e2e 결과 (pwf16 / dotFloat32Float16) — S25 Ultra (V79)

- **일시(date/time):** 2026-06-19 15:01 KST
- **단말:** Galaxy S25 Ultra (SM-S938N), Snapdragon 8 Elite (SM8750, `sun`/`pa3q`), Hexagon **V79**, arm64-v8a, Android 15, ADB `R3CY205ZMND`
- **DSP_ARCH:** **v75** skel (prebuilt 재사용, `build_htp/libhtp_ops_skel.so`. V79 HW는 v75 skel을 하위호환 실행: vN skel은 HW ≥ vN 필요 → v75 ≤ v79 OK)
- **Hexagon SDK:** 6.0.0.2
- **브랜치 / 커밋:** htp_libs_integration @ 5b226f58
- **경로:** `FloatTensor::dotFloat32Float16` → HMX 커널 `hmx_mat_mul_af32_pwf16_of32` (**pwf16**, FP32 activation / pre-permuted FP16 weight / FP32 output)
- **모델:** Qwen3-0.6B, FC(q/k/v/o/gate/up/down)=HMX 32×32 tile-permuted FP16, embed/norm/q_norm/k_norm=FP32, **lm_head=tied(embed_tokens 공유, FP32)**, 28 layers. weight bin 1,814,560,768 bytes.
- **실행자:** j2z0.lee

## 이전 측정 대비 변경 (2026-06-19 14:39 → 본 측정)

1. **`-Dmmap-read=false` 적용** (`package_android.sh -Dwerror=false -Dmmap-read=false -Denable-htp=true`):
   이전 14:39 측정은 `-Dmmap-read=false` 없이 빌드한 `libnntrainer.so`를 사용했음.
   `how-to-use-htp-backend.md` 기준인 `-Dmmap-read=false`를 적용하면 weight를 mmap lazy
   대신 eager read로 로드 → weight 페이지가 프로세스 시작 시 확정적으로 RSS에 포함.
2. **`ENABLE_HTP=1` ndk-build 플래그 추가**: CausalLM 앱이 `nntrainer_causallm` 시작 시
   `htp_ops_open_dsp_session`으로 명시적 HTP DSP 세션을 열도록 컴파일. 이전 14:39 측정 시
   ENABLE_HTP=1 없이 빌드하면 이 호출이 생략되어 `alloc_shared_mem_buf: fastrpc_mmap failed`
   오류와 함께 HTP가 CPU 폴백. `ENABLE_HTP=1` 추가 후 세션 open 정상 → HTP 오프로드 복원.
